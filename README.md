# 🕷️ Spider Calculator

A Spider-Man-inspired Android calculator application designed with a custom themed interface and interactive visual elements.

## 🚀 Features

* Basic arithmetic operations
* Custom Spider-Man-inspired UI
* Multiple themed suit designs
* Calculation history
* Custom expression evaluation
* Web-style visual effects
* Sound effects
* User-friendly interface

## 🛠️ Technologies Used

* Kotlin
* Jetpack Compose
* Android Studio

## 📱 About the Project

Spider Calculator was developed as a creative Android project to explore UI design, application logic, and interactive features while building a functional calculator application.

The project combines a practical calculator with a Spider-Man-inspired visual theme to create a more engaging user experience.

## 🎯 What I Learned

This project helped me improve my understanding of Android application development, Kotlin programming, Jetpack Compose UI design, state management, user interactions, and implementing custom visual and audio elements.

## 📌 Project Status

Completed and available for further improvements and feature additions.
